# Campus Interview Preparation and Process Guidelines

## 1. Purpose
This preparation guide outlines round-wise strategy, role-specific technical expectations, and mandatory behavioral protocols to maximize student success during campus recruitment drives at Vasavi College of Engineering.

## 2. Round-Wise Preparation Strategies
### 2.1 Aptitude & Logical Reasoning Round
- **Structure & Timing:** Typically consists of 60 questions in 60 minutes (Quantitative 40%, Logical Reasoning 30%, Verbal Ability 30%).
- **Target Velocity:** Solve each question within 50 to 60 seconds. Prioritize high-accuracy topics like Data Interpretation, Permutations, and Puzzles.

### 2.2 Technical Coding & Algorithm Round
- **Core Topics:** Arrays, String Manipulation, Linked Lists, Binary Trees, Dynamic Programming, and Graph Traversals.
- **Languages Approved:** C++, Java, or Python 3.
- **Execution Strategy:** Write clean code with optimal time complexity ($O(N \log N)$ or better). Include explicit boundary condition handling.

### 2.3 HR and Behavioral Interview
- **STAR Framework:** Structure answers using the STAR method (Situation, Task, Action, Result) to describe academic or project challenges.
- **Duration:** 15 to 20 minutes focusing on adaptability, teamwork, leadership roles, and company alignment.

## 3. Role-Specific Technical Expectations
### 3.1 Software Development Engineer (SDE)
- Mastery of Data Structures & Algorithms, Object-Oriented Programming (OOP) design patterns, SQL query optimization, and REST API architectural principles.

### 3.2 Core Engineering Roles (ECE / EEE / Mechanical / Civil)
- ECE/EEE: Microcontrollers, VLSI design principles, Digital Signal Processing, and Embedded C programming.
- Mechanical/Civil: CAD/CAM tools (AutoCAD, SolidWorks), Thermodynamics, Fluid Mechanics, and Structural Analysis.

### 3.3 Data & Systems Analyst
- Advanced SQL (JOINs, Window functions, CTEs), Python data analysis packages (Pandas, NumPy), probability, statistics, and BI tools (Tableau/PowerBI).

## 4. Critical Mistakes and Disqualification Flags
### 4.1 Technical Misrepresentation
- Claiming GitHub projects without live demonstration capabilities or repository commit history will result in immediate interview disqualification and T&P disciplinary review.

### 4.2 Dress Code & Punctuality
- **Attire:** Strictly Business Formal (collared shirt, formal trousers, polished shoes, and institutional ID card).
- **Tardiness:** Arriving 15 minutes past the scheduled interview slot results in candidate forfeiture for that recruitment drive.
