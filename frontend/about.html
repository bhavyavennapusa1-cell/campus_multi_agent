System Architecture & Agent Swarm

How our multi-agent system routes and resolves queries.

1. Orchestrator Layer

The primary planning coordinator that parses natural language intent, decomposes requests, and delegates tasks to specialized agents.

2. Specialized Agent Swarm

  • 🎓 Academic Agent: Timetables, attendance metrics, and exam guidelines.
  • 💼 Placement Agent: Company eligibility rules and interview prep.
  • 🎉 Events Agent: Workshop discoveries and registration workflows.
  • 🏢 Student Services Agent: Hostel updates, library access, and FAQs.
  • ✉️ Communication Agent: Notification dispatch and email drafting.

3. Shared Knowledge (RAG) & Memory

ChromaDB vector store over institutional documentation combined with persistent session memory profiles.
